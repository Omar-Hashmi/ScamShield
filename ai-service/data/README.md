# SMS Spam Collection data

`SMSSpamCollection.tsv` contains the original 5,574 messages labeled `ham` or `spam` from the SMS Spam Collection v.1 corpus. ScamShield uses it only to calculate nearest spam and ham text-pattern similarity for text submissions. A match is supporting evidence and cannot by itself label a message a scam.

Source: Almeida, T. & Hidalgo, J. (2011). *SMS Spam Collection* [Dataset]. UCI Machine Learning Repository. [https://doi.org/10.24432/C5CC84](https://doi.org/10.24432/C5CC84)

License: [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). The corpus contains English SMS messages collected from research corpora and spam-reporting sources. Its age, language, and SMS-only scope limit its usefulness for modern multilingual scams, websites, phone numbers, and images.
